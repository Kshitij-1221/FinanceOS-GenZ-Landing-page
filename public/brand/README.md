# Blyth email wordmark

`blyth-lockup-dark-v1.png` is the shared 3x transparent gold-and-white logo for dark-background verification emails. Display at 162×64. It is public and contains no tracking identifiers.

Generated from the landing design and Unbounded font outlines by `../financeos/scripts/generate-brand-assets.swift` (run from the sibling financeos repository). The same generator produces native app icons and this site's `app/icon.png`.

This asset is referenced by both live Supabase code templates. Preserve this versioned URL for already-delivered emails. Use a new filename for future incompatible changes.

Verified publicly available with matching file hashes on 23 October 2026.
